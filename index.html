Project information

This website is a front-end demonstration of the DSA File System Simulator assignment. It provides a visual directory tree, tree traversals, sample graph algorithms and a postfix expression calculator.

Core data structures

  • General Tree — directories and files.
  • Binary Search Tree — file-size indexing concept.
  • AVL Tree — balanced filename indexing concept.
  • Graph — adjacency matrix/list, BFS, DFS, cycle detection, topological sorting and Dijkstra.
  • Expression Tree — postfix expression evaluation.

Implementation note: This standalone website is a JavaScript browser demonstration. It does not connect to or execute the separate C executable. The C program remains the command-line implementation for the assignment.
